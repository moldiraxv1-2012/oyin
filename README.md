# JÍLAN OYÍNÍ

Qaraqalpaq tilindegi Snake oyını. HTML, CSS hám JavaScript bólek fayllarda jaylasqan.

## Iske túsiriw
1. ZIP fayldı ashıń.
2. `JILAN-OYINI` papkasına kiriń.
3. `index.html` faylın eki márte basıń. Oyın brauzerde ashıladı.

## Basqarıw
- Baǵdar kiltleri yamasa W, A, S, D — jılanǵa baǵdar beriw.
- Space — tınıs alıw / dawam etiw.
- Mobil qurılmada ekrandagı baǵdar túymelerin yamasa maydanda swipe qozǵalısın qollanıń.

## Fayllar
- `index.html` — oyın qurılımı.
- `style.css` — bezew hám dizayn.
- `script.js` — oyın logikası.

Joqarı nátiyje brauzerdiń localStorage saqlawında saqlanadı.
